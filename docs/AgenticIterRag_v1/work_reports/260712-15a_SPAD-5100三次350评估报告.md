# SPAD-5100 Stage1 / Stage3 三次 350 数据评估报告

## 1. 结论摘要

本次完成了 SPAD-5100 Stage1 与 Stage3 各三次正式评估，每次使用同一份 350 条评估集。六次评估均为 350 条成功、0 条失败，共生成 2100 条轨迹，并完成 10,000 次、seed 42 的按题配对 bootstrap 聚合。

主要结论如下：

1. **SPAD-5100 Stage1 是本次两个 checkpoint 中准确率更好的版本**：三次均值 EM 0.1705、F1 0.2414。
2. Stage1 相对 Base 和 Search-R1-512 的 EM、F1、完整答案率均显著提升。
3. Stage1 与 Search-R1-5100 均值接近：EM +0.0086、F1 +0.0068，置信区间均跨 0，不能确认 Stage1 显著更好。
4. **Stage3 没有延续 Stage1 的准确率**：相对 Stage1，EM 下降 0.0333，95% CI [-0.0648, -0.0010]，下降显著；F1 下降 0.0298，但置信区间跨 0。
5. Stage3 的搜索行为发生明显收缩：首轮搜索率从 Stage1 的 0.9248 降至 0.4638，平均搜索次数从 2.7676 降至 0.5686。Stage3 推理更快主要与搜索减少有关，不能解释为同等行为下的纯系统加速。
6. 因此，当前推荐保留 **Stage1** 作为 SPAD-5100 的主要评估 checkpoint；Stage3 暂不应替代 Stage1。

Stage3 中 53.62% 的样本完全不搜索，91.91% 的样本最多搜索一次；Stage1 则有 90.19% 的样本至少搜索两次。该变化与 Stage3 的 answer-only Gold-F1 GRPO 训练目标以及训练阶段不在线执行搜索工具的设定一致，说明 Stage3 很可能将策略推向了直接作答。

这里仍需区分相关性与因果性：本次评估能确认 Stage3 出现了搜索收缩和 EM 下降，但不能仅凭评估结果严格证明具体训练组件是唯一原因。与 SPAD-512 Stage3 的搜索率 0.9829 相比，SPAD-5100 Stage3 的行为变化更强；可能与 5100 版本 Stage3 使用 2468 对数据训练 38 step，而 512 版本仅训练 3 step 有关，后续应通过受控消融验证。

## 10. 最终建议

1. SPAD-5100 后续对外汇报与下游使用优先采用 Stage1 `global_step_79`。
2. Stage3 当前不应覆盖 Stage1；它显著降低了 EM，并使搜索策略大幅收缩。
3. 下一步若继续优化 Stage3，应重点检查 answer-only 训练与在线搜索策略之间的目标错配，并用较少 step、KL 约束、混合搜索轨迹或保留 search-policy loss 的受控实验验证。
4. SPAD-5100 Stage1 与 Search-R1-5100 尚未拉开显著差距。后续比较应继续使用按题配对统计，并增加独立训练 seed，而不是只增加同一 checkpoint 的推理重复次数。
