### 2.3 评估协议

- 四个模型使用同一350e parquet。
- no-ranker，Recall Top N=50，模型可见 Top M=5。
- 最多6轮 assistant，`temperature=0.0`，`top_p=1.0`。
- 每个模型执行三次独立推理，共12个 eval run。
- 每次使用唯一 task name、独立 trace/runtime目录和新服务进程。
- 禁止复用 response、trajectory或已有评估输出。
- vLLM单次运行内部 prefix KV cache可以使用，它不复放完整答案。

最终聚合指标包括：

- EM、F1。
- `structured_em`、`answer_group_f1`、`answer_group_recall`。
- 完整答案率、首次搜索率、平均搜索次数。
- 唯一 query 数、重复 query率、最大轮数率。
- 七个数据源的分组指标。

三个 repeat 不直接合并成1050个独立样本。统计时先对同一问题的三次结果取均值，再对350个问题
做 paired bootstrap，默认10000次、seed 42。
